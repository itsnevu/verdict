# VERDICT browser extension

Shows the VERDICT score, label, confidence and one-line reason for the Robinhood Chain token you are viewing on **DexScreener** or **Uniswap**.

Install (unpacked): open `chrome://extensions`, enable Developer mode, **Load unpacked**, pick this folder.
Set the API in the popup (defaults to `https://verdictagent.xyz`; use `http://127.0.0.1:8080` for a local server).

The extension only reads the page URL. It never touches your wallet, never signs anything and never sends page content anywhere.
